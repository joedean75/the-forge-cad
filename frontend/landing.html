Under the hood

Built like an instrument, not a demo.

The parts of DAPS that matter are real: a from-scratch geometry kernel and a genuine optimizer, wrapped in an API an agent can drive.

Kernel
SDF geometry engine
Primitives and booleans evaluated as signed distance fields, meshed by marching cubes.
Solver
3D SIMP optimizer
Compliance minimization on a voxel mesh, GPU-accelerated where available.
Interchange
STEP & STL export
Take the geometry out to any downstream tool, or cut it here.
Agent-native
One typed operation API
Sixteen operations, one mutation path — the same surface the UI and an MCP agent use.
